Popover 分区式

Popover 上半部为 model list（从 API fetch），下半部为分割线 + 齿轮图标「Provider Settings」入口，点击展开配置表单（API Key, Base URL）。配置与选模型在同一 popover 内切换。

Popover 标签页式
