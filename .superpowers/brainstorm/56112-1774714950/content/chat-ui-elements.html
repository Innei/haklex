Chat UI 元素清单

君欲于 agent chat 中呈现哪些 UI 元素？可多选。

1

Streaming Markdown 渲染

流式输出时实时渲染 Markdown（代码高亮、列表、链接等），而非纯文本追加。类似 ChatGPT/Claude 的打字效果。

2

Tool Call 可视化

展示 tool 调用过程：工具名、参数（可折叠 JSON）、执行状态（loading/success/error）、返回结果。

3

Thinking / Reasoning 块

Claude extended thinking 或 chain-of-thought 的折叠展示区，默认收起，可展开查看推理过程。

4

用户干预控制

Stop 按钮中断生成、tool call 执行前用户确认、diff 逐条 accept/reject（已有）。

5

Diff 内联预览（Chat 侧）

在 chat bubble 中直接展示代码/文档 diff，而非仅在编辑器侧标记。用户可在 chat 中快速审阅变更。

6

Agent 状态指示

顶部或底部状态栏：thinking → calling tool → writing → idle。带 spinner 动画。

7

Model / Provider 选择器

下拉切换 Claude / OpenAI，选择具体 model（claude-sonnet-4-20250514, gpt-4o 等）。

8

错误恢复 UI

API 错误、rate limit、网络断开时的友好提示 + 重试按钮。
