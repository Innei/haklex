CodeBlock 语法高亮方案

独立 CodeBlock 组件用于 Streamdown 中的代码块渲染

A

Shiki（@streamdown/code 已用）

与 Streamdown 的 @streamdown/code 插件一致，Shiki 做高亮。高质量 TextMate 语法，主题丰富。

Pros

  • 与 Streamdown code plugin 天然兼容
  • 高亮质量最佳（VS Code 级别）
  • 支持主题自定义

Cons

  • WASM 加载，首次较重（~2MB）
  • 需异步初始化
B

复用项目现有高亮方案

haklex 编辑器中 CodeNode 已有语法高亮实现，直接复用其逻辑抽为独立组件。

Pros

  • 与编辑器风格一致
  • 不引入新依赖

Cons

  • 可能与 Lexical 耦合，需解耦
