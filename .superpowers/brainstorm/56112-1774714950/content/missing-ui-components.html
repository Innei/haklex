rich-editor-ui 缺失组件分析

Chat UI 所需而现有包中未提供的基础组件

现有组件（已可用）

ActionButton, Dialog, Popover, Tooltip, DropdownMenu, Combobox, SegmentedControl, AnimatedTabs, Checkbox, ColorPicker, ViewportGate

1

Collapsible（折叠面板）

Tool call 展开/收起、thinking block 展开详情。@base-ui/react 提供 Collapsible primitive。

用途：ToolCallBubble 参数展开、未来 thinking 可切换折叠

2

Spinner / LoadingIndicator

Agent 状态指示、tool call loading 状态、streaming 中指示器。可设尺寸（sm/md）。

用途：StatusBar、ToolCallBubble loading 态、ChatInput 生成中

3

IconButton（圆形图标按钮）

Stop 按钮、Send 按钮、Accept/Reject 等。ActionButton icon 模式已有，但缺圆形变体和状态色（success/error/warning）。

用途：Stop generation、Send message、tool call 状态圆点

4

Badge / Tag

Tool 名称标签、状态标签（success/error/pending）、model 名称标识。

用途：tool call 工具名、error 类型标签、model indicator

5

Select（下拉选择）

Model 选择器、Provider 切换。DropdownMenu 是菜单语义，Select 是表单语义。@base-ui/react 提供 Select primitive。

用途：ModelSelector（provider + model 二级选择）

6

AutoResizeTextArea

Chat 输入框，自动扩展高度，max-rows 限制。ChatInput 中已有类似逻辑但未抽为组件。

用途：ChatInput 输入框

7

StatusDot（状态圆点）

Tool call 状态（绿/红/黄/灰）、agent 运行状态。小圆点 + 可选动画（pulse）。

用途：ToolCallBubble 状态指示、StatusBar 状态

8

CodeBlock（代码块）

Streamdown components 覆写用。语法高亮 + copy 按钮 + 语言标签。独立于 Lexical CodeNode。

用途：Streamdown 中的代码块渲染

9

ScrollArea（自定义滚动条）

Chat 消息列表滚动容器，自定义滚动条样式，auto-scroll-to-bottom。

用途：ChatMessageList 滚动容器

10

Alert / InlineMessage

错误提示 + 重试按钮。info/warning/error 三种变体。

用途：错误恢复 UI、rate limit 提示

可多选。亦可提出其他所需组件。
