Streamdown 集成方式

Streamdown 依赖 Tailwind CSS，haklex 用 Vanilla Extract。如何共存？

A

仅 demo 引入 Tailwind（隔离层）

demo/ 工程独立加 Tailwind（仅用于 Streamdown），haklex packages 不受影响。Chat bubble 中 Streamdown 组件用 Tailwind 渲染，外部容器仍用 Vanilla Extract。

Pros

  • haklex 包体不引入 Tailwind 依赖
  • demo 自由使用 Streamdown 全部功能
  • 隔离清晰，不污染包

Cons

  • demo 中两套 CSS 方案共存
B

将 Streamdown 作为 rich-agent-chat 的可选 peer dependency

rich-agent-chat 包提供 StreamdownBubble 组件，声明 streamdown 为 peerDependency。消费者自行决定是否引入。

Pros

  • 包级别可复用
  • 不强制 Tailwind

Cons

  • rich-agent-chat 需处理有/无 Streamdown 两种路径
  • Tailwind 与 Vanilla Extract 在包内混用
