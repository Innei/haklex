Tool Call 可视化样式

工具调用过程在 chat 中如何呈现？

A

卡片式（参数可折叠）

每个 tool call 独立卡片：工具名 + 状态图标，点击展开参数 JSON 与返回结果。

🔍 search_document ✓ 完成
参数
{"query": "introduction paragraph", "type": "text"}
结果
Found 2 blocks matching "introduction"
B

紧凑行内式

一行展示：工具名 + 状态。不展示参数细节，hover 显示 tooltip。占空间最小。

✓ search_document → Found 2 blocks
✓ insert_node → Inserted code block
C

混合：紧凑行 + 可展开详情

默认紧凑一行（工具名 + 状态 + 结果摘要），点击可展开完整参数与结果 JSON。

▶ ✓ search_document → Found 2 blocks
▼ ✓ insert_node → Inserted code block 
{"position": "after", "targetId": "block_3", "content": "```js\nconsole.log('hello')\n```"}
