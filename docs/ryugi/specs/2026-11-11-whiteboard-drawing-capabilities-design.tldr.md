# TL;DR：白板绘制能力扩展

完整设计：`2026-11-11-whiteboard-drawing-capabilities-design.md`

## 要做什么

让 AI 只写场景 JSON 就能画出参考图那种白板（便利贴、贴纸、阴影），人在编辑器里还能接着改。新增三项：阴影、SVG 元素、富文本卡片。

## 你会看到的

1. 图形样式面板多一行 Shadow 开关
2. 工具栏多一个 Card 工具（N）：点一下放一张黄色卡片，直接打字
3. 选中卡片里的文字，上方出现小格式条：粗体、颜色、高亮、标题、列表……
4. 粘贴一段 `<svg …>` 代码，画布上出现这张插画，可以拖动缩放
5. 打开验收白板：复刻参考图，文章里和编辑器里画得一样

## 决定

| 项                  | 结果                                                         |
| ------------------- | ------------------------------------------------------------ |
| 范围                | 只做绘制能力，不做 AI 接入                                   |
| excalidraw.com 兼容 | 不保证                                                       |
| 默认风格            | 仍是手绘，AI 自己指定干净风格                                |
| 阴影                | 一个开关，固定柔和阴影                                       |
| SVG                 | 新类型 `svg`，源码在元素里，当图片渲染，只能整体变换         |
| 卡片                | 新类型 `richtext`，自带外观，内容是 Lexical JSON，只放文字类 |
| 卡片高度            | 写定值和内容高度取大，读入时测量                             |
| 卡片编辑            | 白板自带编辑器和格式条，宿主不用改                           |
| 格式参考            | `packages/rich-ext-whiteboard/docs/scene-format.md`          |

## 检查这些（我的判断）

1. 新 peer dependency：`@lexical/rich-text`、`@lexical/list`、`@lexical/link`
2. Card 工具快捷键 N，默认 200×120 黄色
3. 粘贴 `<svg` 文本生成 SVG 元素；`.svg` 文件仍是图片
4. 暗色下卡片随场景整体反色
5. 卡片内边距 12px，文字用 haklex 样式变量
